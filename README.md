# Реплика — нейро-стенографист на Android

Кейс HEX.TEAM «Нейро-стенографист». Нативное Android-приложение: берёт запись встречи, само делит её по участникам, распознаёт речь с временными метками, оформляет текст локальной LLM, строит итоги встречи и выгружает JSON по схеме организаторов. Всё работает на телефоне: в приложении нет разрешения на интернет, облачных API нет, все модели лежат внутри APK.

## Что умеет

- Импорт аудио через системный выбор файла (mp3, m4a/aac, wav, ogg/opus, flac, amr, 3gp и всё, что читает MediaCodec) и через «Поделиться» из других приложений. Запись с микрофона.
- Автоматическая диаризация по голосу: фразы → голосовые отпечатки → кластеризация, число участников определяется само.
- Распознавание: русский (GigaAM v3, сразу с пунктуацией) и английский (Parakeet TDT-CTC 110M), язык выбирается для каждой фразы автоматически.
- Временные метки каждой реплики в целых миллисекундах.
- Локальная LLM (Qwen2.5-0.5B-Instruct через MediaPipe) правит пунктуацию и регистр, не меняя слов, говорящих и времени, и собирает итоги встречи: кратко, решения, открытые вопросы, поручения «что / кому / срок» со ссылками на исходные реплики.
- Расшифровка с плеером: нажатие на время включает запись с этого места, текущая реплика подсвечивается. Переименование участников, правка текста (исходный текст распознавателя сохраняется), поиск, отметка реплик с сомнительным отнесением к говорящему.
- Экспорт JSON строго по схеме и TXT; «Поделиться» и сохранение в файл.
- Библиотека записей с поиском, повторная обработка, удаление. Светлая и тёмная темы.
- Живая запись (1.1.0): текст появляется во время разговора, а не после. Серая фраза — предварительная, после паузы она подтверждается. Голоса помечены как предварительные; после «Завершить» запись проходит полную обработку с участниками, итогами и тем же экспортом JSON. Запись продолжается с выключенным экраном. Если телефон не успевает, приложение пишет об этом, а звук сохраняется целиком. Замеры на эмуляторе: первый текст через 0,6–1 с, задержка обновления 0,24–0,31 с в медиане и меньше 1 с в p95, 16 минут без роста очереди (подробно в [docs/TEST_RESULTS.md](docs/TEST_RESULTS.md)).

## Формат экспорта

```json
{"transcript":[{"speaker_id":"speaker_1","start_ms":1250,"end_ms":4380,"text":"Добрый день!"}]}
```

`speaker_id` стабилен (`speaker_1`, `speaker_2` … по порядку первого появления), имена участников хранятся отдельно и в экспорт не попадают. Перед экспортом проверяется `0 <= start_ms < end_ms <= длительность`.

## Установка

Готовый APK: раздел Releases репозитория (`replika-1.1.0.apk` — с живой записью; прежний `replika-1.0.0.apk` остаётся в релизе v1.0.0, arm64-v8a, Android 8.0+, подписан отладочным ключом). Размер около 1 ГБ: внутри все модели. При первой обработке приложение один раз копирует LLM-модель (521 МБ) из APK во внутреннюю память — MediaPipe читает её только с диска, поэтому нужно ~1,5 ГБ свободного места.

```bash
adb install -r replika-1.1.0.apk
```

## Сборка из исходников

Нужны JDK 17+ и Android SDK 36.

```bash
sh tools/fetch_models.sh
```

```bash
cd src/mobile/android && ./gradlew :app:assembleRelease
```

APK появится в `src/mobile/android/app/build/outputs/apk/release/`. Скрипт `fetch_models.sh` скачивает движок sherpa-onnx (AAR) и модели в `src/mobile/android/app/libs` и `src/mobile/android/app/src/main/assets/models`; в git они не хранятся из-за размера.

Юнит-тесты логики (схема экспорта, сегменты, кластеризация, защита от выдумок LLM, разбор итогов):

```bash
cd src/mobile/android && ./gradlew :app:testDebugUnitTest
```

## Структура репозитория

```
src/mobile/android/   Android-приложение (Gradle, Kotlin, Jetpack Compose)
  app/src/main/java/ru/replika/steno/
    core/    модель данных, декодер, сегменты, конвейер, защита LLM, разбор итогов
    diar/    VAD + голосовые отпечатки + кластеризация
    asr/     распознавание (GigaAM, Parakeet)
    llm/     локальная LLM (MediaPipe + Qwen)
    data/    локальное хранилище, настройки
    export/  JSON по схеме организаторов
    ui/      экраны
tools/                скачивание моделей, эталонный прогон на Mac, оценка, помощник для adb
testdata/             тестовые записи и эталонная разметка
docs/                 архитектура, модели, тесты, ограничения
artifacts/            демо-видео, выгрузки и таблица результатов
```

## Инструменты

- `tools/mac_check.py` — тот же конвейер (VAD, отпечатки, кластеризация, склейка, GigaAM) на компьютере через Python-пакет sherpa-onnx, для сверки и подбора порога.
- `tools/eval.py` — проверка экспортированного JSON: схема, WER, доля времени с верным говорящим.
- `testdata/` — тестовые записи и эталонная разметка.
