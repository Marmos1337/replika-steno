# Материалы демонстрации

- `replika-demo.mp4` — запись экрана реального запуска (Android 16, эмулятор arm64, режим полёта). Видео ускорено в 1,6 раза, звука нет (эмулятор запущен без аудио).
  1. Пустая библиотека → «Импортировать аудио» → системный выбор файла → `ru_dialog_2voices.m4a`.
  2. Обработка: подготовка моделей, участники, распознавание; расшифровка открывается сама, оформление и итоги догоняют в фоне.
  3. Переход к реплике по времени и воспроизведение, переименование участников (имена набраны латиницей: adb не умеет вводить кириллицу).
  4. Вкладка «Итоги» → нажатие на время пункта → переход к реплике и звук с этого места → «Сохранить JSON» и «Сохранить TXT».
- Выгрузки этого запуска: `../test-results/exports/device_ru_dialog_2voices.json` и `.txt`.

## replika-live-demo.mp4 (версия 1.1.0, 1 мин 49 с, без ускорения)

Живая запись на эмуляторе в режиме полёта. Вместо микрофона — тестовый источник отладочной сборки: файл `testdata/ru_dialog_2voices.m4a` подаётся в движок в темпе реального времени. Видно, как предварительная фраза (серая, «распознаётся») появляется во время речи и подтверждается после паузы. После «Завершить» запись проходит полную обработку, и открывается расшифровка с участниками, плеером и итогами. Во время записи видео работал screenrecord, поэтому задержка в этом прогоне выше, чем в замерах из `docs/TEST_RESULTS.md`.
