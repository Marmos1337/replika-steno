# Ограничения решения

## Поддерживаемые условия

- Android 8.0+ (API 26), процессор arm64-v8a. Сборки под 32-битные ARM и x86 нет — так APK меньше.
- Свободная память устройства: около 1,5 ГБ (при первой обработке LLM-модель копируется из APK во внутреннее хранилище). Оперативная память: от 3 ГБ.
- Русская и английская речь. Язык выбирается для каждой фразы автоматически.
- Любой формат, который читает Android MediaCodec. Звук приводится к 16 кГц моно.
- Запись встречи с одного микрофона или созвона, 2–6 участников, речь по очереди.

## Известные ограничения

- Одновременная речь. В каждый момент времени реплика приписывается одному говорящему; перебивания внутри одной фразы без паузы не разделяются.
- Очень похожие голоса и короткие реплики (меньше ~0,5 с) различаются хуже: у короткого фрагмента слабый голосовой отпечаток. Такие места отмечаются «говорящий под вопросом», если модель сама дала низкую оценку.
- Порог кластеризации 0,6 подобран на наших тестовых записях. На записях с сильным эхом или шумом говорящий может разделиться на два кластера, и наоборот.
- Смесь языков внутри одного предложения целиком уходит в одну модель.
- Распознаватели не отдают оценку уверенности по словам. Поэтому «сомнительные фрагменты» отмечаются только по оценке диаризации (кто говорит), а не по качеству распознавания слов. Проценты точности не показываются.
- LLM маленькая (0,5 млрд параметров, окно 1280 токенов). Итоги длинной встречи строятся по первым ~8 окнам по 1600 символов. Формулировки итогов бывают неточными, но каждый пункт ссылается на реальные реплики, а пункты без ссылки отбрасываются. «Кому» и «срок» в поручениях заполняются, только если эти слова есть в процитированной реплике.
- LLM не может менять слова: её правка принимается, только если последовательность слов совпала с исходной. Если модель не справилась, остаётся текст распознавателя.
- Обработка идёт, пока приложение живо. Если система выгрузила процесс, запись помечается «прервано», обработку можно запустить снова.

## Что не входит в текущую версию

- Загрузка моделей из сети (все модели встроены — так требует ТЗ).
- Шумоподавление перед распознаванием.
- Повторная обработка отдельного фрагмента.
- Отправка поручений во внешние сервисы.
- Экспорт в форматы, кроме JSON и TXT.

## Риски демонстрации

- Большой APK (~1 ГБ): установка через adb занимает до минуты.
- Первая обработка дольше следующих: модели загружаются в память, LLM копируется из APK.
- Скорость сильно зависит от телефона. Наши замеры сделаны на эмуляторе Mac (см. TEST_RESULTS.md), на реальном телефоне цифры будут другими.

## Дальнейшее развитие

- Разделение перебиваний по смене голоса внутри фразы (скользящее окно эмбеддингов).
- Более крупная LLM при наличии памяти; модели как отдельные загружаемые пакеты для магазина приложений.
- Словарь терминов команды для распознавания (hotwords в sherpa-onnx).
