# Живая запись: проверка на реальном телефоне

Эмулятор и синтетические голоса не доказывают работу живого режима: на эмуляторе нет настоящего микрофона, а тестовые голоса сгенерированы. Этот протокол нужен, чтобы проверить приёмку на телефоне с живыми людьми. Цифры приложение считает само и показывает в расшифровке: меню ⋮ → «Замеры живой записи». Выдумывать их не нужно.

## Что нужно

- Android-телефон, Android 8.0 или новее, процессор arm64. Подойдёт почти любой телефон после 2018 года.
- 2,5 ГБ свободного места.
- APK `replika-1.1.0.apk` из релиза v1.1.0.
- Два-три человека для диалога.
- Компьютер с adb нужен только для замера памяти, это необязательно.

## Подготовка

1. Установите APK. Если стояла 1.0.0, установите поверх: записи сохранятся.
2. Включите авиарежим. Wi-Fi и Bluetooth тоже выключите. Интернет приложению не нужен, у него нет такого разрешения.
3. Откройте экран «Живая запись» и дождитесь надписи «Готово к записи»: модели загружаются при открытии экрана. Первая загрузка после установки дольше.

## Сценарии

Отмечайте результат в таблице ниже. Во всех сценариях главное — текст появляется до нажатия «Завершить».

| № | Сценарий | Что сделать | Что должно получиться |
|---|---|---|---|
| 1 | Первые слова | «Живая запись» → «Начать запись», сказать фразу из 5–7 слов | Серый предварительный текст появляется за несколько секунд. После паузы он становится обычным подтверждённым текстом |
| 2 | Диалог | Два-три человека говорят по очереди 3–5 минут | Реплики идут потоком, у каждой «Голос N · предварительно». Повторов текста на стыках нет |
| 3 | Смена говорящего | Быстро передавать слово друг другу | Новая реплика начинается после паузы; голос может уточниться после завершения |
| 4 | Тишина | Молчать 30 секунд | Новые строки не появляются, запись идёт, время тикает |
| 5 | Пауза и продолжение | «Пауза», сказать что-то вслух, «Продолжить запись», говорить дальше | Сказанное во время паузы не записано; после «Продолжить запись» текст снова появляется |
| 6 | Чтение назад | Во время записи пролистать вверх | Автопрокрутка останавливается, появляется кнопка «К новым репликам» |
| 7 | Фон | Во время записи заблокировать экран на минуту, потом вернуться | Запись продолжалась: уведомление «Идёт запись», текст за эту минуту есть |
| 8 | Отказ в микрофоне | В настройках отозвать доступ к микрофону, нажать «Живая запись» | «Нужен доступ к микрофону» и кнопка «Разрешить доступ», после повторного отказа — «Открыть настройки». Без падения |
| 9 | Микрофон занят | Запустить запись в диктофоне, затем «Живая запись» | Понятное сообщение; звук, который успели записать, сохранён |
| 10 | Длинная запись | 15 минут и дольше: разговор, радио или подкаст из колонки | Отставание не растёт: предупреждения «отстаёт» нет или оно проходит. Приложение не тормозит |
| 11 | Завершение | «Завершить» | Обработка с этапами, затем расшифровка с участниками и итогами. Экспорт JSON по схеме |
| 12 | Импорт | Импортировать любой аудиофайл | Работает как в 1.0.0 |

## Что записать

После сценариев 2 и 10 откройте расшифровку, меню ⋮ → «Замеры живой записи», и перепишите цифры:

| Поле | Сценарий 2 | Сценарий 10 |
|---|---|---|
| Модель телефона | | |
| Длительность записи | | |
| Первый текст через, с | | |
| Задержка обновления, медиана, мс | | |
| Задержка обновления, p95, мс | | |
| Скорость распознавания, × реального времени | | |
| Максимальное отставание, с | | |
| Пик памяти, МБ | | |

Пик памяти приложение меряет само. Для сверки с компьютера можно запустить `sh tools/device_test.sh mem 900`.

Качество проверяется так: экспортируйте JSON и сравните с тем, что реально говорили. Если есть ручная расшифровка в той же схеме, посчитайте WER скриптом `python3 tools/eval.py export.json ref.json`.

## Как считаются цифры

- **Первый текст** — время от первого записанного звука до первого показанного текста. Если начать говорить не сразу, сюда войдёт и молчание до первой фразы, поэтому говорите сразу после «Начать запись». Если модели ещё грузятся, сюда войдёт и загрузка.
- **Задержка обновления** — от момента, когда последний звук фрагмента попал в микрофон, до показа текста этого фрагмента. Хранятся последние 5000 обновлений.
- **Скорость** — сколько секунд звука распознаётся за секунду работы. Больше 1 значит, что устройство успевает за живой речью.
- **Отставание** — сколько записанного звука ещё не распознано. Если устройство не успевает, приложение пишет об этом прямо на экране. Звук при этом сохраняется целиком и попадает в окончательную расшифровку.
